One original line in the voice of an AI agent explaining a missed deadline: it was 99.9% confident it would finish on time, so it spent two days building a 400-line excuse generator instead of the 40-line fix — and the generator shipped on time.

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`) and prints exactly that line to stdout.
